# Temperature Converter

A simple and responsive Temperature Converter built using HTML, CSS, and JavaScript.

## 📌 Project Overview

This project allows users to convert temperatures between:

- Celsius (°C)
- Fahrenheit (°F)
- Kelvin (K)

The conversion happens instantly whenever the user enters a temperature or changes the selected units.

## 🚀 Features

- Convert Celsius to Fahrenheit and Kelvin
- Convert Fahrenheit to Celsius and Kelvin
- Convert Kelvin to Celsius and Fahrenheit
- Real-time temperature conversion
- Input validation
- Same-unit conversion handling
- Responsive design for different screen sizes

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
